# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.4.x   | Yes       |
| < 1.4   | No        |

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report them privately via GitHub: open the repository's **Security** tab and choose **Report a vulnerability** (private vulnerability reporting).

Include the affected version, your OS, and steps to reproduce. You can expect a first response within a few days.
